# Arbeitsweise BuntwerkStudio (Kurzfassung für dieses öffentliche Repository)

Dieses Repository ist öffentlich, und GitHub Pages zeigt jede Datei darin im Internet. Darum stehen hier **keine internen Abläufe, Namen von Zugangsdaten, Gutschein-Details, Adressen interner Projekte oder Pfade**.

Die vollständige Arbeitsanleitung (`ARBEITSWEISE.md`) liegt nur in den privaten Repositories `BuntwerkStudio/Klangform` und `BuntwerkStudio/tracks-and-trails`. Ein Agent liest sie dort, bevor er etwas ändert.

Für dieses Repository gilt:

1. Hier nie Zugangsdaten, Gutscheincodes, interne Adressen, E-Mail-Adressen von Mitarbeitern oder Abläufe zu Zahlung und Gutscheinen eintragen. Was nicht öffentlich sein darf, gehört in die privaten Repositories.
2. Texte auf Deutsch, Leser mit „du“, kurze klare Sätze.
3. Diese Seite kostet keine Netlify-Credits (GitHub Pages): nach lokaler Prüfung direkt auf `main`.
4. Projektregeln: `CLAUDE.md`. Aufgaben: `AUFGABEN.md`, Ablauf: `README.md`, Abschnitt „Aufgaben abarbeiten“.
